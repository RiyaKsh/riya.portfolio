# Assets

Everything in `public/` is served as-is. A file at `public/assets/images/design/cafe.jpg` is used in content as `"/assets/images/design/cafe.jpg"`.

| Folder | Use for |
|---|---|
| `images/design/` | design project previews, case-study mockups |
| `images/engineering/` | screenshots and diagrams |
| `images/content/` | video thumbnails, photo-dump images, archive stills |
| `images/marketing/` | campaign visuals |
| `images/about/` | your portrait |
| `images/profile/` | creator avatar |

Tips: use `.jpg`/`.webp`, keep files under ~300 KB, use lowercase names with dashes, and always fill in the matching `...Alt` field.
